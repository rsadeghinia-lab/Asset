# دستیار اموال دانشگاه — نسخه آزمایشی موبایل (PWA)

## آزمایش بدون IT دانشگاه
1. محتویات این ZIP را در یک پوشه استخراج کنید (فایل‌ها را جدا از هم بارگذاری نکنید).
2. برای نصب روی موبایل و دسترسی به دوربین زنده، پوشه را روی یک میزبان **HTTPS** قرار دهید. یک گزینه آزمایشی GitHub Pages است: مخزن آزمایشی خالی ایجاد کنید، این فایل‌ها را در ریشه بارگذاری کنید، Settings → Pages → Deploy from branch → main / (root) را انتخاب کنید و نشانی HTTPS منتشرشده را در Chrome اندروید باز کنید. انتشار می‌تواند کمی زمان ببرد.
3. در Chrome اندروید: منوی سه‌نقطه → Install app یا Add to Home screen (بسته به مرورگر).
4. فایل XLSX را از طریق کابل/اشتراک فایل به موبایل منتقل کنید. در خود اپلیکیشن به «ورود اطلاعات» بروید و آن را **یک‌بار** انتخاب، ستون‌ها را بررسی و تأیید کنید.
5. دفتر مالی / انبار (دانشکده) / مکان را تعیین کنید و بارکد را اسکن کنید. پلاک خارج از فایل نیز با توضیح قابل ثبت است.
6. پس از آزمون خروجی/پشتیبان JSON تهیه کنید. پاک‌شدن داده مرورگر یا تغییر دامنه باعث از دست رفتن داده محلی می‌شود.

## محدودیت‌های مهم
- GitHub Pages و خدمات مشابه برای **انتشار فایل‌های برنامه** است، نه برای آپلود فایل اکسل واقعی یا اطلاعات محرمانه در مخزن عمومی. اکسل را فقط از داخل اپ در گوشی وارد کنید؛ برنامه محلی است و ورود اکسل آن را به سرور ارسال نمی‌کند.
- نسخه آزمایشی سرور همگام‌سازی ندارد. هر گوشی مستقل است؛ برای چند گروه باید داده‌ها تجمیع شوند.
- فایل‌های `.xlsx` با خواننده محلی قابل پردازش‌اند؛ برای `.xls` قدیمی ممکن است اینترنت/کتابخانه اضافه لازم باشد. بهتر است فایل را از Excel به `.xlsx` تبدیل کنید.
- قابلیت دوربین با BarcodeDetector به مرورگر/دستگاه وابسته است. شماره OCR فارسی بدون بارکد هنوز وجود ندارد.
- PWA پس از اولین بارگذاری موفق می‌تواند فایل‌های برنامه را آفلاین باز کند. داده‌های پیش‌تر واردشده در مرورگر می‌مانند، اما این جایگزین پشتیبان‌گیری نیست.
- نسخه اولیه دارای حساب کاربری/رمزگذاری اختصاصی/سرور امن نیست؛ اطلاعات واقعی اشخاص را فقط در موبایل قابل اعتماد و با تأیید مسئول مربوطه وارد کنید.
- برنامه روی سرویس HTTPS خارج از دانشگاه *بدون بارگذاری اکسل در سرور* قابل آزمایش است، اما سیاست محرمانگی دانشگاه ممکن است استفاده از میزبان بیرونی را محدود کند.
